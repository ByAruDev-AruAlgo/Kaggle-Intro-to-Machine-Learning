
# Kaggle Intro to Machine Learning

My notes, explanations, and solutions for the [Kaggle Learn Intro to Machine Learning course](https://www.kaggle.com/learn/intro-to-machine-learning).

This repository documents my progress through the course, with custom notes to reinforce concepts and solutions to practice exercises.

## Contents

- **Notes** — Personal explanations, examples, and key concepts.
- **Exercise Solutions** — My solutions to the course's coding exercises.

## Topics Covered

- How Models Work
- Basic Data Exploration
- Your First Machine Learning Model
- Model Validation
- Underfitting and Overfitting
- Random Forests
- Machine Learning Competitions
